# 配套实践：每章一个入口，一个综合项目

先读[正文目录](../SUMMARY.md)，再进入对应实践。第 0～2 课理解历史、判断与职责，不要求额外写程序；第 3～11 课各有一个实践入口，第 11 课复用第 6 课的跨进程实验。第 12 课先做正文内的纸面检索与回答练习，不要求安装数据库。

每课按同一个顺序学习：先预测结果，运行最小演示，再改变一个条件，最后解释正常与失败结果。实现已经完成，不需要先清空函数。检查通过只说明相应行为得到验证，不能替代自己的解释和改动。

## 能力积累在哪里

[Workspace Agent](workspace-agent/README.md) 是持续维护的综合实现。第 3 课复用其工具循环；第 5～6 课观察其上下文与恢复行为；第 9～10 课直接使用它完成任务和接受验收。运行各课演示时，仓库已提供完整代码，不要求先做完所有关卡。

安全与 Tracing 保留独立机制实验。交接和子任务恢复是第 10 课的选做演示，尚未全部集成为后台系统。

阶段实践从一个小需求开始：先手写调用顺序、停止条件或恢复决策中的一个关键判断，再用既有检查验证。通用 Python、模型 SDK 和测试脚手架按需阅读，不需要重复实现。

[SQLite](optional/sqlite/README.md) 是选做存储专题。目录分页和乘法最小循环可从第 3 课入口按需进入，均不增加必做课次。

## 运行约定

命令从仓库根目录执行。默认演示和检查只用 Python 标准库、预设模型、临时文件或本机进程。第 7 课系统沙盒对照需要支持 `sandbox-exec` 的 macOS；这项系统拒绝证据不能由其他平台的模拟输出代替。

只有显式使用 `--live` 的入口才调用真实模型。需要时在虚拟环境中安装 `openai`，配置 `OPENAI_API_KEY`、`OPENAI_MODEL` 和可选的 `OPENAI_BASE_URL`。真实调用可能产生费用；各入口限制请求和超时，设置见本课说明。不要把 Key 写入教材、命令记录或报告。

维护者可以一次运行所有离线检查：

```bash
python -B practice/check.py
```

这不是读者额外的作业。历史模型报告保留原始路径和代码指纹，目录迁移后仍表示当时的实验，不能当作当前版本重新通过的证据。
