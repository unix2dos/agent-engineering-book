# 第 5 课实践：历史保留，输入变短

先读[第 5 课：上下文工程](../../chapters/05-上下文工程.md)。本课观察完整轮次压缩，不要求接入摘要模型。

## 必做

```bash
python -B practice/lesson-05/demo.py
```

演示保留最近一轮已完成对话和当前用户消息，把更早的一轮替换为预设摘要。终端显示压缩前后的会话输入字符数，磁盘原始历史仍完整保留；过长摘要被拒绝，文件不变。

在 [demo.py](demo.py) 中把 `KEEP_RECENT_TURNS` 从 `1` 改成 `2`，先预测是否还有旧轮次能压缩。再次运行应显示“发生压缩：False”，原视图保留。这个参数同时控制切点选择与压缩，其他验证不需要修改。

## 完成标准

能说明摘要、保留尾部和新消息如何组成下一次输入；没有可压缩轮次时为什么应保留原状态；摘要失败或变长时为什么不能写入成功记录。

```bash
python -B practice/lesson-05/check.py
```

检查覆盖正文片段、完整轮次边界、工具消息配对、连续压缩和失败时文件不变。演示与检查复用[综合项目](../workspace-agent/README.md)的 `maybe_compact()`，不再保留另一套完整 Agent 或不同的 Split Turn 实现。

字符数只用于同口径的教学比较，不是 Token 计量。摘要为预设文字，长度检查不能证明语义完整；固定指令、工具说明和输出预留仍须计入真实请求预算。
